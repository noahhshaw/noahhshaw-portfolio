# Drizzle migrations

Generated by `npm run db:generate`. Each `*.sql` file is a forward-only
migration produced by diffing `src/db/schema.ts` against the previous
migration state (tracked in `meta/`).

## Applying

For this project, prefer `npm run db:push` (state diff against live DB) over
running these SQL files directly. The portfolio DB already contains the
names-rater tables, so the initial migration here intentionally re-declares
them as `CREATE TABLE` — that would fail on an existing database. `push`
inspects state and only emits diffs.

If you ever migrate to a fresh DB:

```sh
DATABASE_URL='postgres://...' npx drizzle-kit migrate
```
